# Aplikasi Kas Forum PPPK

Aplikasi desktop offline untuk pengelolaan kas & iuran Forum PPPK (Tauri + React + SQLite, 100% lokal).

- Jalankan dev: `npm run dev` (vite) atau `npm run tauri dev`
- Build: `npm run build` + `cargo check` — installer di `src-tauri/target/release/bundle/`
- Panduan lengkap: `public/Panduan_Penggunaan_Aplikasi_Kas_Forum_PPPK.pdf` & halaman Petunjuk di aplikasi
